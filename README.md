# Spicy Cravings — One-page React + TypeScript site

This is a small Vite + React + TypeScript one-page website that reproduces the layout of the provided design. Components are separated into `src/components`.

How to run (Windows / bash):

```bash
# from e:/Files/FAITH/website
npm install
npm run dev
```

This will start the dev server (Vite). Build with `npm run build` and preview with `npm run preview`.

Files of interest:
- `src/components/Hero.tsx` — top hero banner
- `src/components/ProductGrid.tsx` — product showcase
- `src/components/BusinessPlan.tsx` — business plan sections
- `src/components/Footer.tsx` — footer

Adjust styles in `src/styles.css` to better match imagery or add real photos in `public/`.
